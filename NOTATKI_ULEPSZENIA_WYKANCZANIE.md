# Notatki: ulepszenia wykańczania

Ustalenia i zmiany wykańczania. Nierozwiązane punkty są oznaczone [ ].

- [x] W bibliotece receptur dodać wybór statusu: aktywne / nieaktywne. Status archiwalny ustalimy później.
- [x] W danych zlecenia zmienić etykietę „Wykończalnia” na „Wykańczalnia”.
- [x] W oknie „Ostatnia produkcja” dodać pole na notatkę dla wykańczalni.
- [x] Przy sekcji „Sztuki załadowane do zlecenia” dodać strzałkę wskazującą możliwość rozwinięcia.
- [x] Przy załadowanej recepturze dodać ikonkę otwierającą podgląd całej receptury.
- [x] Sekcję „Historia wykonań” w recepturze zrobić zwijaną i rozwijaną strzałką.
- [x] W oknie przyjęcia Enter prowadzi kolejno przez „Przyjęte wg wagi (kg)” → „Przyjęte sztuki” → metry sztuki → gramaturę z belki → szerokość z belki.
- [x] Przy wpisywaniu sztuk dodać możliwość powielenia tej samej wartości dla wielu belek, np. wpisać 300 mb i liczbę 7, aby dodać 7 osobnych belek po 300 mb.
- [x] Korekta specyfikacji wysyłkowej PM synchronizuje usunięte i dodane belki w powiązanej specyfikacji wykańczania, zachowując ręcznie wybrany podzbiór oraz historię przyjęć.
- [x] Pole „Powtórz ×” znajduje się bezpośrednio przy polu metrów, bez odsuwania na prawą stronę formularza.
