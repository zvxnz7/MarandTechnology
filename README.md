# MarandTechnology

The application, database tools, backups, and GitHub release updater run on
Node.js 24.15 or later. The server does not need Python or npm dependencies.

For Windows Server, download this public repository as a ZIP, extract it, and
run `INSTALL_SERVER.cmd`. Follow [SERVER_QUICKSTART.md](SERVER_QUICKSTART.md).
After each push to `main`, GitHub Actions publishes a versioned update that an
administrator can install from the app's **Aktualizacje GitHub** page.
